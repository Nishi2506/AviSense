# Bird-strike risk labelling pack

**The labelling guide (`avisense-risk-labelling-guide.md`) has not been added to this folder yet.**
Please wait for it before you start labelling. It explains what each risk level means.

## What is in this folder

- `clips/`: the video clips (`clip_001.mp4`, `clip_002.mp4`, and so on).
  - Each clip is 25–30 seconds long, at 1920×1080 and 25 frames per second.
  - The time in seconds is shown in the top-left corner.
  - A **yellow box** surrounds each bird. The bird is the small dot inside the box.
  - The **red outline** marks the runway zone.
  - Some corners are blacked out on purpose.
- `storyboards/`: one picture per clip showing one frame per second, for a quick overview.
- `clips_index.csv`: the length and time of day of each clip.
- `labels_template.csv`: the file to fill in. Add one row for each stretch of time you label.

The clips play in VLC or the Windows Media Player / Films & TV app. Some web browsers cannot play them.
